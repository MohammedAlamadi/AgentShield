# Implementation Deviations and Document Reconciliation

Records every difference between the submitted Deliverable 1 plan and the actual Deliverable 2 implementation, and every conflict found between the reference documents. Order of authority: D1 report (technical design) → assessment brief (submission and grading) → master prompt (engineering process) → handover (context).
